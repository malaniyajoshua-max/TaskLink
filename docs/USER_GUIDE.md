# TaskLink 用户指南

## 任务、项目和视图

在“我的任务”中可以快速创建任务，再补充描述、项目、优先级、截止时间、提醒和子任务。列表支持按到期时间、优先级、最近更新或标题排序，也能按今日、逾期和高优先级筛选。看板按待办、进行中、已完成分列；拖动或点击状态按钮会更新同一条任务。全局搜索可以直接跳到任务，批量工具可统一调整项目、优先级、日期、状态或删除多条任务。

“今日”包含今天到期的任务和仍未完成的逾期任务；“即将到期”显示今天起七天内的任务。日历适合按日期查看和补录，提醒页集中展示将要触发的项目。创建任务时如果正处在今日或未来视图，会自动填入当天 23:59，可继续修改。

## 父任务与子任务

每个父任务可以拥有若干个一级子任务。子任务的标题、描述、状态和项目始终独立；截止时间、优先级和提醒可以分别选择“跟随父任务”，也可以关闭相应继承后独立设置。用户显式批量修改某项属性时，该项会自动转为独立设置，避免父任务随后覆盖明确选择。

完成状态采用双向联动：

- 完成父任务时，所有未完成子任务一并完成。
- 取消父任务完成时，父任务回到未完成状态，子任务恢复联动前各自的状态。
- 所有子任务都完成后，父任务自动完成；任一子任务重新打开时，父任务同步回到未完成。
- 状态撤销会核对父子成员和当前状态；期间若已有其他修改，系统拒绝过时撤销，避免覆盖新数据。

当继承值与子任务独立值冲突时，以开关为准：开启继承就使用父任务当前值，关闭继承就使用子任务值。服务端版本冲突不会静默覆盖，应用会提示选择保留本机版本或接受服务器版本。

## 提醒和提示音

到达提醒时间后，TaskLink 会发送 Windows 系统通知。通知正文默认隐藏任务标题，可在“设置 → 通知”开启内容预览。启用提示音后会播放内置提示声；也可以选择本机音频作为自定义提示音，并随时恢复默认声音或关闭声音。点击系统通知会显示主窗口并定位到相关任务。

关闭主窗口时应用默认留在系统托盘，进程仍在运行，因此到时间仍可提醒。若从托盘菜单彻底退出、Windows 注销、电脑关机，应用进程不在运行，便不会在该时刻主动发声；下次启动会重新读取提醒状态。Windows 的勿扰模式、应用通知权限、音量和输出设备也会影响通知是否可见或可听。

## 专注、撤销和离线工作

任务可启动专注计时，支持暂停、继续和完成统计。计时保存绝对结束时间，电脑休眠或窗口节流不会把截止时间向后拖；专注完成不会自动完成任务。状态修改提供短时撤销，任务复制可以选择是否带上子任务。

已登录账号可离线创建和编辑任务。写入先进入本地加密数据库与同步队列，网络恢复后自动上传。服务器版本发生变化时会进入冲突处理，不会静默丢弃一方内容。JSON 导出是明文，适合数据迁移；需要安全存放时使用带独立口令的 `.tlbackup` 加密备份。

## 协作和聊天

工作区拥有者可以邀请成员并分配权限。好友接受后可打开独立聊天窗口；再次打开会复用现有窗口，任务窗口可以同时继续工作。Enter 发送，Shift+Enter 换行。文字草稿和待发送附件保存在本地账号数据库中，重启后可恢复。

聊天支持 PNG、JPEG、GIF、WEBP，以及 TXT、MD、CSV、JSON、PDF、DOCX、XLSX、PPTX、ODT、ODS、ODP、ZIP 和 7Z。单个附件上限 25 MiB，单条消息最多 5 个附件，本机待发送总量上限 125 MiB。附件先进入待发送列表，只有点击发送后才上传；下载会校验 SHA-256，并由 Windows 标记为来自网络。

## 八套季节主题

“设置 → 外观”提供春日、春夜、夏日、夏夜、秋日、秋夜、冬日、冬夜八套完整主题。每套主题同时调整背景、卡片、边框、强调色、文字、按钮和装饰，并在主窗口与聊天窗口间同步。主题按账号保存在本机；还可以选择经典浅色、经典深色或跟随系统。主题卡片会即时预览，点击后立即生效。

## 设置内容

- **账号**：查看 TaskLink 账号和邮箱，修改昵称与头像，退出登录。
- **外观**：季节主题、经典主题、跟随系统、界面密度与相关显示偏好。
- **通知**：系统通知、正文预览、提示音、自定义提示音文件。
- **任务视图**：默认排序、列表/看板选择、是否在主列表显示子任务等。
- **数据保护**：JSON 导入导出、创建口令加密备份、恢复备份。
- **同步与更新**：查看同步状态、处理冲突、检查配置好的签名更新。

布局、主题、排序、通知选择和专注记录按账号保存在当前电脑；任务和协作数据按同步规则保存。切换账号时不会沿用上一账号的主题或临时筛选。
